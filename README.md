# CloudMusic Player

## 项目简介

一款简约现代的网页音乐播放器。
本项目旨在学习 GitHub 和软件开发全流程。

## 功能规划

- [ ] 本地音乐导入
- [ ] 音乐播放与暂停
- [ ] 上一曲与下一曲
- [ ] 播放进度调节
- [ ] 音量调节
- [ ] 播放列表
- [ ] 随机播放
- [ ] 循环播放
- [ ] 深色主题
- [ ] 手机界面适配

## 技术栈

- HTML：页面结构
- CSS：界面设计
- JavaScript：功能实现
- GitHub Pages：网页部署

## 开发计划

1. 初始化项目仓库
2. 建立开发任务
3. 实现基础播放功能
4. 完善播放器界面
5. 测试与修复
6. 部署与发布
